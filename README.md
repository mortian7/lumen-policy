# Lumen: Ex Tenebris — sitio público

Sitio estático para la política de privacidad de Lumen en Google Play.

| Ruta | Contenido |
| --- | --- |
| `index.html` | Página de privacidad y punto de entrada del sitio |
| `assets/css/styles.css` | Estilos, colores y reglas para pantallas pequeñas e impresión |
| `assets/images/` | Banner y futuras imágenes del sitio |

Para revisar la página localmente, abre `index.html` en el navegador. Las rutas de los recursos son relativas y funcionan también al alojar el sitio bajo `/lumen-policy/`.

Agrega estilos en `assets/css/` e imágenes en `assets/images/`. Si el sitio crece, cada página adicional puede tener su propia carpeta con un `index.html`. Si cambia el contenido de la política, sincroniza el texto con el que se muestra dentro del juego.
